What is consistent across all four
  • Top nav — same position, same spacing, same typography, same tab labels. Only the active underline + accent color shifts per tab.
  • Logo / name — always Newsreader serif 600 in top-left.
  • Footer status bar — same height, same monospace, same small-caps. Content reflects the active persona (changelog, places, catalog, builds).
  • Type hierarchy — H1 size, body size, label size: identical scale across all four tabs. Only typography color/style shifts.
  • Editorial restraint — no metaphor chrome, no decorative SVG, no theatrical transitions. The variety is in body design language only.

If this is the right shape, say "lock it" and I’ll write the design spec. Else tell me: tab labels wrong (Coder vs About vs Engineering?), I want a logo not just text, Maker page too dark, etc.
