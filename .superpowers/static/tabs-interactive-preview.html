Per-tab interaction patterns — in plain words
§1 Coder
  • Project cards scroll-trigger their tech chips (50ms stagger fade-in)
  • Hover any tech chip → cross-filter: all projects using it brighten, rest dim
  • Live agent feed at top (already in spec)
  • /changelog footer status (already in spec)
§2 Traveler
  • Horizontal polaroid timeline — drag/swipe/scroll-wheel
  • Year markers fixed at intervals (2019 / 2021 / 2023 / 2024 / 2026)
  • Click polaroid → photo lightbox + travel note expands
  • "Currently · next stop" indicator with date countdown
§3 Curator
  • "Currently reading" hero card with rotating quote (daily or per-visit)
  • Honest subtitle: "Building this catalog. One book at a time."
  • "Recently finished" mini-list — grows as you add
  • Later: tabs/filters for Books / Fragrance / Music when content grows
§6 Maker
  • Dashed-outline "FIG. 1 · placeholder" with soft pulse (intentional, not lazy)
  • "Build queue · planning" list visible immediately (you have ideas, that’s real)
  • When first sketch lands → placeholder swaps to schematic, queue auto-updates
  • Page is visibly building itself over time, like all the others

If the interaction direction is right, say "lock it" and I’ll write the spec. Else: "Coder needs a horizontal projects scroller too," "Traveler should have a map not polaroids," "Curator: also list fragrances even though I only have 2," "Maker: the pulse is too much," etc.
