§1 Coder · Stagger reveal + tag cross-filter

Project cards stagger-fade their tech chips on scroll-in. Hover any chip → all cards lacking it dim to 0.25 opacity. Click = persistent filter.

§2 Traveler · Horizontal polaroid timeline

shadcn/Carousel embla-carousel-react + wheel-gestures

Drag, swipe, scroll-wheel, arrow keys all work for free. api.on('select') drives sticky year-marker header. Free-drag mode (no snap) for the timeline feel.

// drop into your repo with:
// npx shadcn@latest add carousel

const [carouselRef, api] = useEmblaCarousel(
  { axis:"x", dragFree:true, loop:false },
  [WheelGesturesPlugin()]
)
// L113-122 of shadcn carousel.tsx:
api.on("select", () => setActiveYear(
  places[api.selectedScrollSnap()].year))

§3 Curator · Currently reading + quote rotation

Astro Content Collections Zod schema 0 KB JS

Pure server-render. Drop a .md per book. Daily quote rotation is deterministic date-modulo (stable across page navs, changes daily).

// src/content.config.ts
const books = defineCollection({ type:'content',
  schema: z.object({
    title: z.string(), author: z.string(),
    status: z.enum(['reading','finished']),
    started: z.date(), finished: z.date().optional(),
    rating: z.number().min(1).max(5).optional(),
    quote: z.string().optional(),
}) })
// dayIdx = Math.floor(Date.now()/86_400_000) % quotes.length

Cross-cutting

  • Astro <ClientRouter /> for tab-to-tab route transitions. transition:name on the active tab pill = morphing underline. Built-in Astro 4.x.
  • prefers-reduced-motion — Motion auto-respects. Tailwind motion-safe: / motion-reduce: variants for everything else.
  • Performance: All four patterns hydrate client:visible (not client:load), so above-fold paint is HTML-only. LCP locked to the H1.
  • Content model: Everything that grows over time (books, places, projects, builds) becomes an Astro Content Collection with a Zod schema. Adding a new entry = git commit a .md file. No CMS, no deploy config.
