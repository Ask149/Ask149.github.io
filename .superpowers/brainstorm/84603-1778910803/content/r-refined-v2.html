§ 1 Four agents in parallel

I run four coding agents concurrently. They do not compete. They occupy different quadrants on a two-axis grid — latency and autonomy. Copilot inside the function. Claude Code for exploration. OpenCode for systems. Jules for delegation.1

The amount of code I write per day has dropped roughly seventy percent. The number of decisions I make has gone up by about the same. Senior IC value used to be “I can write this fast and right.” In 2026 it is “I can frame the problem so an agent finishes it without going wide.”2

Design principles applied
  • Engineering paper — radial-gradient dot pattern (22px grid, 10% opacity). Geeky without going terminal.
  • Microtype — § section marks, hanging chapter numeral (No. 03 / 2026), small-caps mono labels with 0.18em–0.22em letter-spacing, proper en-dashes & em-dashes, OldStyle figures (font-feature-settings).
  • Tufte sidenotes — superscript footnote markers in body text (¹ ²) referenced by margin notes in mono small-caps. Reads as a research paper.
  • Modular scale — type sizes lock to a 1.25 ratio (0.58 / 0.65 / 0.8 / 0.88 / 0.98 / 1.02 / 1.6 / 2.6 rem). Predictable rhythm.
  • Asymmetric grid — two-column body (1fr / 110px) so marginalia has a real lane. Hero is single-column for impact.
  • Color discipline — 3 functional colors (ink, paper, copper) + 2 neutrals (rule, faint). Copper shifted slightly more saturated (#B85838) for ink-on-paper feel.
  • Edge cases handled — body ink is #15110A (warmer than pure black) for paper-warmth; copper accent only on active state + edit signal; rule color is desaturated.
What stayed
  • Same information architecture — no copy or structure changes
  • Self-writing manuscript metaphor
  • Drop cap (now larger and more breath)
  • Live datum embedded in a sentence (Lee Robinson)
  • Copper rule + marginalia for fresh edits
  • /changelog footer status bar
