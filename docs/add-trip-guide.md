# Adding a New Trip

This guide covers the end-to-end workflow for adding a new place entry to the Voyages section.

## Quick path

If you already have a folder of 1-10 photos, prefer the local uploader:

```bash
npm run trip:upload -- \
  --slug 2026-12-tokyo \
  --title "Tokyo" \
  --country Japan \
  --country-code JP \
  --lat 35.6762 \
  --lon 139.6503 \
  --photos ~/Pictures/tokyo
```

See `docs/trip-upload-guide.md` for all options.

Manual scaffold path:

```bash
# 1. Scaffold the place file + photo folder
npm run trip:new -- 2026-12-tokyo "Tokyo" 35.6762 139.6503

# 2. Drop 1–10 photos into public/photos/2026-12-tokyo/
#    Rename as: 01-cover.jpg, 02-something.jpg, ... up to 10-final.jpg
#    First file MUST start with "01-" (cover).

# 3. (optional) Add captions.yaml in the photo folder
# 4. Run validate + optimize + regenerate manifest
npm run photos

# 5. Run AI paragraph generation (free, Gemini 2.0 Flash)
npm run paragraphs
```

## Folder and filename spec

Every trip lives in two parallel locations, keyed by the same slug:

- `src/content/places/<slug>.md` — frontmatter + body
- `public/photos/<slug>/` — 1–10 photos + optional captions.yaml

**Slug format:** `YYYY-MM-<location-kebab>` — e.g. `2026-12-tokyo`, `2027-03-lisbon`.
The script enforces this regex; legacy slugs (the 4 pre-existing ones) are grandfathered.

**Photo filenames:** `NN-descriptive-words.jpg` where `NN` is `01`, `02`, ..., `10`.
- `01-` prefix is mandatory on the cover photo (the script fails the build if missing).
- Allowed extensions: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
- Photos wider than 2000px are auto-resized on `npm run photos` (sharp).
- 1–10 photos required per trip. Folders with 0 photos are treated as placeholders (warn, don't fail).

## Captions and copy

### Filename → caption (default)

`02-narita-morning.jpg` automatically becomes the caption `narita morning`.

### captions.yaml (override)

Drop `public/photos/<slug>/captions.yaml` to override per-photo captions:

```yaml
01-cover.jpg: "Arriving at Narita on a wet October morning"
02-narita-morning.jpg: "The first cup of vending-machine coffee"
03-shinjuku-night.jpg: "Shinjuku, midnight, still raining"
```

Keys are the exact filename. Missing keys fall back to the kebab-to-spaces default.

### Paragraph copy (AI vs hand-written)

The narrative paragraph that anchors each place comes from one of two sources:

| `paragraphAuthor` value | Meaning |
|---|---|
| `ashish` / `ak` | Hand-written. Never overwritten by AI runs. |
| `gemini-2.0-flash` / `ai` | Generated by `npm run paragraphs`. Skipped on subsequent runs unless... |
| `ai-regenerate` | Sentinel — next `npm run paragraphs` regenerates this entry. |

Default state for a fresh scaffold is no `paragraph` field at all → `npm run paragraphs` fills it in and stamps `paragraphAuthor: gemini-2.0-flash`.

To hand-write: set the paragraph manually + add `paragraphAuthor: ashish`.

### Choosing a Gemini model

The script defaults to `gemini-flash-latest` (auto-tracks newest stable flash model). To override:

```bash
# Default — auto-tracks newest stable flash model
npm run paragraphs

# Pin to a specific version (if -latest moves and you want stability):
GEMINI_MODEL=gemini-1.5-flash npm run paragraphs
GEMINI_MODEL=gemini-2.5-flash npm run paragraphs

# Higher quality (still free tier):
GEMINI_MODEL=gemini-pro-latest npm run paragraphs
```

If `-latest` aliases give region-quota errors, fall back to `gemini-1.5-flash` — it has the widest free-tier availability.

If you see `limit: 0` errors, the script prints actionable fallback steps — follow them in order.

## mapCoords (percentage positioning on the world-map SVG)

`mapCoords.leftPct` and `mapCoords.topPct` are percentage offsets on the world-map SVG (NOT lat/lon — those live in `geo`). To derive them:

1. Open `src/components/traveler/WorldMap.astro` and check the viewBox / dimensions.
2. Open the rendered site (`npm run dev`) and use browser DevTools to hover over your target location on the map.
3. Read the pixel offset and convert to a percentage of the SVG width/height.
4. Update `mapCoords` in `src/content/places/<slug>.md`.

The scaffold script leaves these as `0` / `0` — you must fill them manually before the pin will land in the right place.

## EXIF date suggestion

If the cover photo (`01-*.jpg`) has a `DateTimeOriginal` EXIF tag and the place file has no `timelineLabel`, `npm run photos` prints a suggested label in the console. The suggestion is **never** auto-written — you control the copy.

## Validation gates

`npm run photos` (which runs automatically before every `npm run build`) will fail the build if:

- A folder under `public/photos/` doesn't match the slug regex (and isn't a grandfathered legacy slug).
- A folder has 11+ photos.
- The first sorted photo doesn't start with `01-`.

These are intentional — they prevent broken or partial trips from shipping.

## Example: scaffold output (Tokyo)

When you run `npm run trip:new -- 2026-12-tokyo "Tokyo" 35.6762 139.6503`, the script produces this file at `src/content/places/2026-12-tokyo.md`:

````yaml
---
title: Tokyo
country: TODO
countryCode: XX
yearMonth: 2026-12
reason: leisure
coverAlt: Tokyo cover image
geo:
  - 35.6762
  - 139.6503
mapCoords:
  leftPct: 0
  topPct: 0
timelineLabel: Tokyo 2026
photoFolder: 2026-12-tokyo
paragraph: >-
  Tokyo in December 2026 was a city of sharp, blue-glass days and air that felt
  like a thin blade against my skin. My time there was unanchored, a period of
  leisure that felt less like a vacation and more like a quiet drift. I spent my
  afternoons in basement ramen shops, the steam from the pork broth fogging my
  glasses while the world hummed overhead. Every evening, I performed the same
  small ritual: pressing a button for a hot can of black coffee from the vending
  machine near the station. The heat of the aluminum seeped into my palms, a
  temporary fortification against the deepening cold. There was a particular,
  muted loneliness in watching the crowds from the periphery of a subway
  platform. On my last night, the wind shifted. A single yellow ginkgo leaf,
  brittle and dry, scraped a slow circle across the dark asphalt.
paragraphAuthor: gemini-flash-latest
---
Tokyo. TODO short body line.
````

You'd then fill in:

- `country: TODO` → `country: Japan`
- `countryCode: XX` → `countryCode: JP`
- `mapCoords.leftPct` / `mapCoords.topPct` → real percentages (open `src/components/traveler/WorldMap.astro`, hover the spot, derive)
- Drop 1–10 photos into `public/photos/2026-12-tokyo/` named `01-cover.jpg`, `02-...`, etc.
- (Optional) write a hand-typed `paragraph:` or leave blank for Gemini to fill

Then `npm run photos && npm run paragraphs && npm run build`.
